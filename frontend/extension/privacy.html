TriVex privacy information

This page describes the current version of TriVex.

What TriVex does

When you click Analyze, TriVex checks the text of one URL against six URL features using rules that run inside your browser.

What stays on your device

  • The URL you analyze and the result are processed locally.
  • TriVex does not send URLs, results or any other data to a server.
  • TriVex does not save your analysis history.

What TriVex does not do

  • It does not open or fetch the URL it analyzes.
  • It does not read page content, passwords or form fields.
  • It does not scan pages in the background or block navigation.

Permission used

  • activeTab: lets TriVex read the address of the current tab only after you click the TriVex icon and choose "Analyze current page".

Limits

URL-only checks can miss clean-looking phishing links and can warn on legitimate sites. "No high-risk indicators detected" does not mean a site is verified safe.

If TriVex gains new features that need more permissions or handle more data, this page will be updated to match.
