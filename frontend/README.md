# Frontend — TriVex Chrome Extension

This directory will contain the Chrome Extension Manifest V3 popup and local URL-analysis interface.

Planned files:
- `manifest.json` — extension configuration and minimal permissions.
- `popup.html` — user interface.
- `styles/popup.css` — styling.
- `scripts/popup.js` — popup interactions.
- `scripts/detector.js` — URL feature extraction and detection methods.

This is a scaffold, not a complete detector. Avoid broad permissions and automatic URL fetching.
